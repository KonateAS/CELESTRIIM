# Illustrations CELESTRIIUM

These SVGs are original, locally authored vector illustrations. They use the CELESTRIIUM palette, contain no external image references, and are deliberately abstract: they do not depict a named client, a completed assignment, or measured results.

| File | Intended use |
| --- | --- |
| `impact-territoires.svg` | Home hero and institutional pages |
| `expertise-strategie.svg` | RSE strategy expertise |
| `expertise-projets.svg` | Impact project engineering expertise |
| `expertise-communication.svg` | Responsible communication expertise |
| `expertise-partenariats.svg` | Partnership expertise |
| `demo-projet-territoire.svg` | Clearly marked project demonstration, not a real reference |
| `demo-mesure-impact.svg` | Draft demonstration about impact tracking |
| `editorial-perspectives.svg` | Editorial and perspectives pages |
| `reference-rivotra.svg` | Symbolic cover illustration for the RIVOTRA Freedom Cup reference; not official event artwork |
| `reference-cdc-immersion.svg` | Symbolic cover illustration for CDC Immersion; not a photograph or official branding |
| `reference-audiovisuelle.svg` | Symbolic cover illustration for event communication and audiovisual production |


The image records and their selectable paths are registered in the migration `20261023220000_local_visuals_and_drafts`. Editors can replace a cover in **Administration → Bibliothèque média**: upload a JPEG, PNG, or WebP image, add its alternative text, then select it in the content editor. Uploads are checked, auto-oriented, resized within 2000 × 2000 pixels, converted to WebP, and stored under `public/uploads/`.

The two demonstration articles remain drafts. The three published references use symbolic local cover illustrations rather than photographs or official client artwork. Each image is registered in the media library and can be replaced through the administration screen.

## Illustrative photographs

The `photos/` folder contains general editorial photographs used decoratively in public page headers. They are stock illustrations, not documentary images of CELESTRIIUM projects or partner organizations. Photographer and download links are recorded in `photos/credits.md`.
